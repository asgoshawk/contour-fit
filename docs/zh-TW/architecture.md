# 架構摘要

[English architecture](../architecture.md) 是主要規格。

`contour-fit-core` 負責純資料運算，公開專案自己的型別；
`contour-fit` 負責 PNG 解碼、參數、SVG／JSON 與診斷影像。

流程為：保留像素強度 → Marching Squares → 輪廓包含階層 →
弧長取樣與尖角保護 → 受限最小平方擬合與分割 → 獨立誤差／拓撲驗證 →
相鄰曲線合併 → SVG 座標量化與再驗證。

平滑接點維持 G1，尖角只要求 G0。第一版不加入 LM、動態外掛或平行排程；
先取得比較測試與效能證據。取樣、分割、曲線數與圖片解碼均有資源限制。

採 TDD：先建立可觀察行為的失敗測試，再實作與重構。
版本、分支與發布驗收以 [英文發布文件](../releases.md) 為準。
